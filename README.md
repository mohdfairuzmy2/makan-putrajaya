# 🍽️ Makan Putrajaya

**PWA - Cari Lokasi Makanan Menarik di Putrajaya**

Aplikasi web progresif (PWA) untuk mencari, berkongsi, dan mempromosikan lokasi makanan menarik di sekitar Putrajaya.

## ✨ Ciri-ciri

- 🏠 **Senarai Lokasi** - Papar semua lokasi makanan dengan carian & penapis kategori
- 📍 **Tambah Lokasi** - Pengguna boleh tambah lokasi baru dengan muat naik gambar
- 🏪 **Daftar Kedai** - Peniaga boleh daftar kedai, masukkan maklumat & menu
- 📄 **Butiran Lokasi** - Paparan penuh maklumat kedai termasuk menu & harga
- 🔍 **Carian & Penapis** - Cari mengikut nama, alamat, atau kategori
- 📴 **Offline Ready** - Boleh diakses tanpa internet selepas dipasang

## 🚀 Mula

```bash
npm install
npm run dev
npm run build
npm run preview
```

## 📱 PWA Features

- Service Worker (offline caching)
- Web App Manifest (boleh dipasang pada telefon)
- Mobile-first responsive design
- Bottom navigation (UX seperti app)

## 🛠️ Tech Stack

- React 18 + Vite 5
- React Router v6
- vite-plugin-pwa
- localStorage (data persistence)
